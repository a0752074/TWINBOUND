## Gameplay regression

The suite covers all four destinations; date-dependent launch states; supported date endpoints; moving-body gravity; numerical convergence; physical encounters; navigation guidance; fuel and energy; route stability; impact cores; supply awards; original score formulas; save migration; pause, abort, debrief and report export.

3D checks cover six-direction input, normalized combined thrust, equal fuel use at equal thrust, normal-axis burns, coasting, depth-aware collisions and collection, deterministic encounter depths, switching without state resets, normal-axis guidance and a separate 25% bonus. Switching alone earns no bonus. Controlled 3D missions complete at all four destinations with the same base scores and science results as the corresponding 2D cases.

The actual application and trajectory worker run in an in-process DOM adapter. It exercises planning, mission configuration, all destinations, 2D/3D switching, keyboard handlers, fuel use, pause/resume, abort, saved records and JSON export. Canvas calls are checked for finite coordinates. A separate test makes the resource manifest unavailable and confirms normal offline flight still starts.

Mission Viz checks compare the tutorial-derived ellipse and Kepler timing with independent numerical propagation. State/element round trips cover elliptic, hyperbolic, circular, equatorial, polar and retrograde cases. The retained Horizons hash/interpolation tests verify cached source bytes, date guards and measured interpolation fixtures. No out-of-range extrapolation is introduced. The cache rebuild log from the unchanged dataset is retained in `data/validation/cache_rebuild.log`.

## Visual and platform scope

The actual cockpit drawing routine is checked at desktop and narrow mobile sizes. Deterministic SVG previews are generated by `node tools/render_cockpit.mjs`; the included PNGs are rasterizations of those previews. Their Canvas adapter approximates gradients and does not provide browser layout or text metrics.

A complete browser rendering session was not executed in this environment. Actual browser layout, keyboard/touch timing, audio playback, fullscreen behavior and cross-browser performance remain manual checks. Windows and macOS launchers were reviewed but not executed on those operating systems.

GMAT is **Not Executed**. Only the matched point-mass case, script, local reference and comparison utility were prepared. No external GMAT output or numerical agreement is claimed. The synthetic comparison unit test validates the comparison math only. See `GMAT_VALIDATION.md`.

Controlled missions establish internal integration, not player success rates, complete hardware qualification or independent validation of the full multi-body model.

```sh
npm run evidence
npm run gmat:prepare
python -m compileall -q run.py tools
```

Only development checks require Node.js 18+. Offline play needs Python 3.10+ and a modern browser.
