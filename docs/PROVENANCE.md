# Source provenance

The numerical ephemerides come from NASA/JPL Horizons. Raw responses, query parameters and SHA-256 records are retained in `data/horizons_v10`. Archived photographs retain their original image bytes and credits in `data/photos.json`.

Document-derived methods and their source sections are indexed in `data/nasa-resources.json`. Original source downloads reviewed for this release are identified by URL and SHA-256 in `data/evidence/source-snapshots.json`.

Mission Viz analysis is an independently written, tutorial-derived implementation. No NASA repository source was copied. The reviewed repository snapshot does not establish a repository-wide license for the tutorial; the component-specific X3Dom license was not applied to other files.

Development assistance is listed in `AI_USAGE.md`. Software and external-data terms are separated in the project `LICENSE`.
