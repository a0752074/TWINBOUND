# Development credits

OpenAI ChatGPT / Codex provided extensive assistance with implementation, code revision, debugging, tests, English localization and documentation. The participant directed the game concept, visual goals, controls, feature choices and revisions.

There is no runtime generative-AI service. The NASA/JPL ephemerides and credited archive photographs are external scientific data. Game graphics, the cockpit and sound effects are produced by procedural Canvas/SVG and Web Audio code. Equipment and service values are educational assumptions.

Source citations, numerical assumptions and validation scope are documented separately in `NASA_RESOURCES.md`, `PHYSICS.md` and `VALIDATION.md` and `VALIDATION_v10.3.1.md` (current release). `VALIDATION_v10.3.0.md` retains its original scope.
